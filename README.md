🚀 Talent Management Platform
An AI-powered Talent Management Platform designed to help students and users improve their learning, technical skills, assessment performance, and interview preparation through an integrated digital platform.
📌 About the Project
The Talent Management Platform provides a structured environment where users can learn from study materials, practice assessments, interact with an AI assistant, analyze their resumes, and prepare for interviews.
The platform also includes an Admin module that allows administrators to manage users, documents, exams, and announcements.

📊 Platform Overview
📚 Learning Portal
The Learning Portal provides a structured 36-day learning journey.
Users can:
Select a learning day.
Open the corresponding PDF material.
Study the provided content.
Mark the lesson as completed.
Unlock the next learning day after completing the previous lesson.
Attend assessments after completing the required learning days.
Unlock the AI Voice Mock Interview based on assessment performance.
📝 Assessment System
The platform provides AI-based assessments based on the learning materials.
The learning flow is:
Day 01 → Day 02 → Day 03 → Day 04
                  ↓
              Day 05 Exam
                  ↓
             Score > 70%
                  ↓
          AI Voice Mock Interview
🎤 AI Voice Mock Interview
The AI Voice Mock Interview helps users practice real interview situations.
It includes:
Basic introduction questions
HR-related questions
Technical questions
Voice-based answers
AI-based response evaluation
Performance feedback
The system evaluates areas such as:
Technical Knowledge
Communication
Strengths
Areas for Improvement
Overall Performance
